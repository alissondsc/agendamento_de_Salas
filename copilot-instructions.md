# Contexto

Este é um sistema de reserva de salas de uma escola.
Onde o foco são os professores e/ou outros funcionarios solicitar uma reserva, e o gerente de salas aprovar a solicitação.

# Tecnologias

## Frontend
Para o frontend é usado html, css, javascript moderno.

## Backend
Para o backend é usado node com javascript.
Para o banco dados é usado mysql, porém em ambiente local usamos o mysql em docker.

# Arquitetura
o frontend e backend são criados em diretórios separados, e ligados por API.
A criação do backend utiliza o TDD (Test-drive development).

# Para criar as features
Utilize commit semantico.
Se as instruções da feature não estiverem claras questione ao invés de supor.
